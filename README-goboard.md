# Go Board Camera Stream

碁盤をスマホのカメラで撮影し、認識結果をリアルタイムにブラウザで中継するための単一HTMLアプリ。

公開: https://heheyilang2212-oss.github.io/go-board-stream/

## 特徴

- カメラ → 盤面認識 → 配信 / 観戦 がブラウザ完結（サーバ不要）
- 9路 / 13路 / 19路 対応
- 4隅をタッチで合わせるだけ（ホモグラフィで全交点を逆引き）
- 局所中央値ベースの2パス分類で、不均一な照明にも対応
- 連続フレーム多数決＋オクルージョン棄却で安定動作
- 着手履歴の自動記録 → SGFダウンロード（FF[4] 準拠）
- WebRTC P2P 中継（[PeerJS](https://peerjs.com/) 公開ブローカ）
- 配信用URLは永続化（同じ部屋IDが翌日も使える）
- 観戦側でも SGF ダウンロード可
- 盤面PNGスナップショット、最終手取消、90°回転、手数表示

## 動作要件

- **HTTPS必須**: `getUserMedia` はHTTPSまたは `localhost` でのみ動作（GitHub Pages はHTTPS）
- **モダンブラウザ**: iOS Safari 13+, Chrome/Edge/Firefox 最新
- 外部依存: PeerJS（CDNから読み込み）。CDNが落ちている場合は配信不可

## 使い方

### 配信側（碁盤の前にいる人）

1. スマホで本ページを開く → 「配信する」
2. カメラ許可
3. カメラ映像に映る碁盤の **四隅の交点**（一番外側の縦線と横線が交わる点）に、黄色のハンドル1〜4をドラッグで合わせる
4. 「設定」を開いて検出強度などを調整（必要に応じて）
5. 表示される **部屋ID** または **視聴URL** を観戦者に共有

### 観戦側

- 共有された URL を開くだけ。`?view=部屋ID` で自動接続
- 切断時は自動再接続
- 観戦側でも SGF / PNG ダウンロードや音・手数表示の切替が可能

### SGF出力

- 配信開始時の盤面が初期局面（AB / AW）として記録される
- 以後の着手が `;B[..];W[..]...` として時系列で追記される
- そのまま OGS, KGS, sabaki, EidoGo 等で開ける

## トラブルシュート

- **石が認識されない**: 設定の「黒の検出強度」「白の検出強度」を調整 / 「認識結果をカメラに重ねて表示」をオン
- **盤面が歪む**: 4隅のハンドルが**交点**にあるか確認（盤の縁ではない）
- **手が映ると認識が乱れる**: 自動的に棄却されるので静止すれば戻る
- **PeerJS 接続エラー**: 公開ブローカが一時的に落ちている可能性。少し待つか「↻」で新ID発行

## 技術メモ

- 検出: 各交点から半径 `0.3 × グリッド間隔` の円形パッチをサンプリングし、`max(R,G,B)` の中央値を計算
- 分類: グローバル中央値からの偏差で初期分類 → 各セル周囲の「空」と分類されたセルの中央値を局所基準にして再分類
- 安定化: セル毎に直近Nフレームの多数決（70%以上一致で確定）
- オクルージョン棄却: 直近受理フレームから一定セル数以上が変化した場合は履歴に積まない（手が映った時など）
- ホモグラフィ: 単位正方形から任意四角形への閉形式
- 通信: PeerJS の DataConnection で `{committed, moves, initialPosition, turn, ts}` を都度送信（80msスロットル）
